# jvm-check

Проверка логики хранилища и плейлистов (вложенные папки, переименование, перенос, удаление, подпапки в плейлистах, защита от `../`)
на обычной JVM, без Android SDK и эмулятора. Классы Android берутся из `android-all` (Robolectric). Запуск: `cd tools/jvm-check && gradle run`
(нужен Gradle и JDK 21; тест создаёт временные файлы и печатает `storage + playlists tests passed`).

Тест не затрагивает то, что требует настоящего Android: декодирование картинок, отрисовку, сервисы.
