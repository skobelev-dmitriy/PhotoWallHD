# PhotoWall vision (распознавание областей для «живых» фото)

Маленький HTTP-сервис: получает фото → находит области, которые можно оживить (вода, листва/пальмы, небо, человек, ткань/флаг),
строит для каждой **маску** с мягким краем, говорит, что это, и **рекомендует эффект с параметрами**
(формулы и параметры: [../docs/EFFECT-SPEC.md](../docs/EFFECT-SPEC.md)). Проектор отправляет сюда фото и получает «рецепт»
для показа. Сервис можно держать в Docker на ноутбуке/домашнем сервере, позже перенести на VPS.

## Бэкенды

| `BACKEND` | Что это | Статус |
|---|---|---|
| `classical` | Без нейросети и без загрузок: эвристики по цвету, текстуре и положению (небо, вода, растительность). Грубый, но работает везде; запасной вариант. | Проверен тестами и на реальном снимке. Путает тёмные небеса, ночные кадры. |
| `segformer` | SegFormer (ADE20K, 150 классов сцены: море, вода, дерево, пальма, трава, небо, человек, флаг …). Модель по умолчанию `nvidia/segformer-b2-finetuned-ade-512-512` (`MODEL_ID`). Если модель не загрузилась, сервис сам переключается на `classical`. | Код написан, но **не запускался с реальными весами** (в среде разработки нет доступа к HuggingFace). Нужна проверка у вас. |

Позже сюда можно подключить OpenRouter/ИИ-модель для уточнения рекомендаций; сейчас не используется.

## Запуск

```
cd vision
docker compose up --build        # segformer; первая сборка скачивает torch и веса
# или без модели:
docker build -t photowall-vision . && docker run --rm -p 8090:8090 photowall-vision
```

Без Docker: `pip install -r requirements.txt && uvicorn app.main:app --port 8090` (для segformer ещё `torch` и `requirements-segformer.txt`,
`BACKEND=segformer`).

Откройте `http://localhost:8090`: тестовая страница покажет, что «увидела» модель (цветные области, границы, подписи),
анимированный предпросмотр (движение ×3 для наглядности) и рекомендации.

## API

- `GET /health` → `{"ok":true,"backend":"classical","model":null}`.
- `POST /analyze` — тело: байты картинки (или multipart с полем `file`). Ответ — рецепт (`version`, `image`, `backend`, `layers[]`),
  у каждого слоя `id`, `class`, `label`, `effect`, `params`, `confidence`, `enabled`, `bbox`, `area`, `note` и `mask_png_b64`
  (PNG маски 8 бит). Плюс `id`, `preview_url`, `overlay_url`, `seconds`.
- `GET /preview/{id}.gif?gain=3&width=640` — зацикленная анимация (хранится в памяти последние 16 фото).
- `GET /overlay/{id}.png` — фото с раскрашенными областями, границами и подписями.

## Тесты

```
pip install -r requirements.txt pytest httpx
python -m pytest -q          # 16 тестов: формулы эффектов, классы меток, выделение областей, API
python tests/gen_reference.py   # пересоздать tests/reference.json (общие числа с приложением)
```

## Ограничения

Классы ADE20K не различают «волосы» и «платье»: у человека пока только едва заметное «дыхание». Качество масок на краях определяет модель;
мягкий край (feather) сглаживает швы. Фото уменьшается до 512 px по длинной стороне для анализа; маски растягиваются на оригинал.
