# PhotoWall HD

Android-приложение, которое превращает проектор (или телевизор) в картину на стене: показывает **ваши** фотографии
на весь экран, до 4K, с часами, расписанием и режимом заставки. Сделано под Wanbo T2 Ultra, но работает на любом
Android 6.0+ (API 23; Android TV, проекторы, приставки, планшеты).

## Возможности

- **Загрузка фото по сети.** Приложение запускает на проекторе маленький веб-сервер. Открываете адрес
  (например `http://192.168.1.50:8080`) в браузере телефона или компьютера, перетаскиваете фото —
  и они сразу попадают в показ. Оригиналы сжимать не нужно.
- **Фото до 4K и больше.** Большие снимки (12–50 Мп) масштабируются под разрешение экрана без потери резкости,
  EXIF-поворот учитывается.
- **Папки и плейлисты:** фото по папкам, загрузка папки целиком, плейлисты («утро», «вечер», «по запросу») с окнами времени. См. [docs/PLAYLISTS.md](docs/PLAYLISTS.md).
- **Плавный показ:** растворение / сдвиг, медленное приближение (Ken Burns), «целиком / на весь экран / авто»,
  случайный порядок, интервал от 5 секунд до часа, затемнение для тёмной комнаты.
- **Часы и дата** поверх картинки: положение, размер, 12/24 часа.
- **Расписание:** вне заданного времени экран чёрный. Вечером в «время включения» показ продолжается сам.
- **Автозапуск:** при включении проектора и при открытии приложения (с 5-секундным отсчётом, который можно отменить).
- **Дискотека / цветомузыка:** 8 алгоритмических эффектов (спектр, круг, кольца, осциллограф, три лампы, фейерверк, звёзды, холмы)
  под музыку из браузера на компьютере (YouTube и др.), микрофона, звука устройства или встроенного демо. Подробнее: [docs/DISCO.md](docs/DISCO.md).
- **Заставка:** можно выбрать «PhotoWall HD» в Настройки → Заставка (если ваша прошивка это поддерживает).
- **«Живые» фото:** сервис распознавания (Docker) находит воду, листву, небо, людей и предлагает лёгкое движение; проектор рисует его при показе. См. [docs/LIVE-PHOTOS.md](docs/LIVE-PHOTOS.md), [vision/](vision/README.md).
- **Предпросмотр на веб-странице:** поле «Сейчас на экране» — статичный кадр текущего фото (без эффектов) или снимки дискотеки примерно 2 раза в секунду.
- **Управление с телефона:** вперёд / назад / пауза / запуск показа и все настройки — на той же веб-странице.
  Можно задать PIN-код.
- **Управление через Claude (MCP):** «включи дискотеку», «добавь эту картину», «смена раз в минуту» — см. [docs/MCP.md](docs/MCP.md).
- Управление пультом: ← → — предыдущее/следующее, OK — пауза, ↓ или Menu — настройки, Назад — выход.

## Установка

1. Скачайте `PhotoWallHD.apk`: вкладка **Actions** → последняя успешная сборка → артефакт `PhotoWallHD-apk`
   (или со страницы **Releases**, если создан тег `vX.Y.Z`).
2. Установите на проектор: скопируйте APK на флешку и откройте файловым менеджером проектора
   (нужно разрешить установку из неизвестных источников), либо по сети: `adb connect <ip-проектора>` и
   `adb install PhotoWallHD.apk`.
3. Запустите **PhotoWall HD**. На экране появится адрес — откройте его на телефоне в той же Wi-Fi сети.
4. Загрузите фото и нажмите «Запустить показ».

### Чтобы показ сам включался вечером

- Для запуска из фона на Android 10+ нужно разрешение «Показ поверх других окон»: кнопка есть на главном экране
  приложения (появляется, если разрешения ещё нет).
- Включите «Автозапуск показа» в настройках — тогда приложение стартует вместе с проектором.
  Если прошивка не запускает приложения при загрузке, добавьте PhotoWall HD в автозагрузку в настройках проектора.
- Экран «чёрный» не равен выключенному проектору: лампа/светодиод при чёрной картинке почти не светит,
  но для полного выключения используйте таймер самого проектора.

## Сборка

Проект без внешних зависимостей (только Android SDK). Локально: `./gradlew assembleRelease`
(нужны JDK 21 и Android SDK 36; Android Studio сама предложит всё установить). В репозитории настроен GitHub Actions (`.github/workflows/build.yml`),
который собирает APK при каждом push. Подпись — фиксированный ключ из `app/debug.keystore`,
поэтому новую версию можно ставить поверх старой без удаления.

Документация: [docs/](docs/) (архитектура, API, проверка по ADB, дискотека, плейлисты, MCP, «живые» фото, планы).

Фото хранятся в `Android/data/app.photowall/files/photos/` на проекторе.
