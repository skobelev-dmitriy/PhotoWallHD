# Состояние проекта и передача дел

*Для следующей сессии (или для вас утром). Обновлять после больших изменений.*

## Сделано (ветка `ccr-9574af34-ocqfdd`)

Слайд-шоу своих фото (до 4K, часы, расписание, заставка), веб-управление и встроенный сервер, дискотека (звук из браузера), плейлисты и вложенные папки
с файловым интерфейсом, «живые» фото (контейнер `vision/`), MCP-сервер, инструменты сборки (AGP 9.4, Gradle 9.8, JDK 21, SDK 36),
**диафильмы** (импорт `.cbz`, плеер «Проектор», см. [FILMSTRIPS.md](FILMSTRIPS.md)). Продуктовые заметки: [PRODUCT-IDEAS.md](PRODUCT-IDEAS.md).

## Что проверено, а что нет

- Проверено: компиляция приложения (Kotlin 2.4.21 против Android 17 API; предыдущие версии собирались в GitHub Actions), логика хранилища, плейлистов
  и импорта диафильмов на обычной JVM (`tools/jvm-check`, включая настоящий `film_8126.cbz`), формулы эффектов (Python = Kotlin), веб-страница в браузере
  на подставном проекторе (Playwright), `vision/` (16 тестов), MCP (`npm test`).
- **Не проверено ни разу:** приложение на реальном проекторе Wanbo T2 Ultra (внешний вид, плавность, нагрузка), Docker-образ `vision/`, SegFormer
  с настоящими весами, «живые» фото и проигрыватель диафильмов на экране.

## Решения, принятые без владельца (поправьте, если не так)

- Диафильм по умолчанию листается **вручную**; таймер необязателен (5–60 с). Оформление по умолчанию «Проектор».
- Диафильмы лежат отдельно от фото (`filmstrips/`), в слайд-шоу не попадают.
- Импорт только `.cbz/.zip` с картинками; названия кадров не используются как пути.
- Каталог Stripa — только как предложение контракта в `FILMSTRIPS.md`; на устройстве пока кнопка «Каталог (скоро)» неактивна.
- Звук (озвучка, шум проектора) намеренно не делался.
