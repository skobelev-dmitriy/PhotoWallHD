# Заметки: общая основа с проектом ADS Network

Эти заметки составлены по описанию владельца: у проекта ADS Network есть Android-приложение для показа рекламы,
есть первый заказчик, тестировать удобно на Android-проекторе. Сам код ADS Network мне пока не доступен, поэтому
ниже — не выводы из кода, а то, что в PhotoWall HD уже можно использовать как есть.

Что полезно переиспользовать:

- **Встроенный HTTP-сервер** (`HttpServer`, `WebApi`): приём файлов потоком, JSON-API, PIN. Нужен, если рекламу
  нужно заливать напрямую в устройство, а не только с облака.
- **Показ с переходами и предзагрузкой** (`SlideshowView`, `BitmapLoader`): держит 4K без нехватки памяти.
- **Расписание «окно работы»** (`Prefs.inActiveWindow`) и автозапуск при включении (`BootReceiver`, `ServerService`).
- **CI-сборка APK** (`.github/workflows/build.yml`): готовый APK в Actions на каждый push.

Чего не хватает для рекламы и нужно решать отдельно:

- Видео (сейчас только изображения), длительность показа на каждый ролик/баннер.
- Отчёты о показах (proof of play) и их отправка на сервер.
- Привязка устройства к аккаунту, получение расписания и креативов из облака, офлайн-режим.
- Защита: подписанный пакет, HTTPS, управление доступом.
