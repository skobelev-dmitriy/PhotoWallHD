# Установка и проверка на проекторе через ADB

## 1. Подготовка проектора

1. Настройки → О системе → 7 раз нажать «Номер сборки» (включится режим разработчика).
2. Настройки → Для разработчиков → включить отладку (по USB и, если есть, по сети / Wi-Fi).
3. Подключить проектор к той же Wi-Fi сети, что и компьютер; узнать IP (Настройки → Сеть или список клиентов в роутере).

## 2. Подключение

`adb` лежит в `platform-tools` Android SDK (Windows: `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`).

```
adb connect 192.168.X.X:5555
adb devices          # проектор должен быть в статусе "device"
```

На проекторе подтвердите запрос «Разрешить отладку». На Android 11+ отладка по Wi-Fi может требовать
сопряжения: `adb pair IP:порт` и код с экрана проектора.

## 3. Установка и запуск

```
adb install -r PhotoWallHD.apk        # или собрать: ./gradlew assembleDebug
adb shell am start -n app.photowall/.MainActivity
adb shell appops set app.photowall SYSTEM_ALERT_WINDOW allow     # запуск показа из фона
```

## 4. Логи

```
adb logcat -s AndroidRuntime:E        # падения
adb logcat --pid=$(adb shell pidof app.photowall)
```

## Чек-лист проверки

- [ ] Приложение появилось в списке приложений и запускается.
- [ ] На главном экране виден адрес `http://<ip>:8080`; страница открывается с телефона в той же сети.
- [ ] Загрузка нескольких фото (в том числе 12+ Мп и портретных) проходит, миниатюры появились.
- [ ] Показ идёт, переходы плавные, нет рывков на 4K; фото с телефона повёрнуты правильно.
- [ ] Кнопки пульта: ← → листают, OK — пауза, ↓/Menu — настройки, Назад — выход.
- [ ] Часы и дата отображаются, формат и положение меняются.
- [ ] Расписание: вне окна экран чёрный, в начале окна показ возвращается.
- [ ] После перезагрузки проектора сервер доступен, показ запускается (если включён автозапуск).
- [ ] Показ работает несколько часов подряд без роста потребления памяти (`adb shell dumpsys meminfo app.photowall`).
- [ ] Заставка: Настройки → Заставка → PhotoWall HD (если прошивка поддерживает).

Известные неизвестные (не проверялись на устройстве): поведение на прошивке Wanbo при загрузке, наличие экрана
выбора заставки, работа «показа поверх других окон», максимальный размер текстуры GPU.

## Если не работает

| Симптом | Что проверить |
|---|---|
| `adb connect` не отвечает | Включена ли отладка по сети; тот же ли Wi-Fi; `ping` проектора; не включена ли «изоляция клиентов» в роутере. |
| Страница не открывается | Адрес и порт на главном экране; фаервол Windows; не гостевая ли сеть Wi-Fi. |
| Показ не стартует сам | Разрешение «поверх других окон»; автозапуск в настройках приложения; автозагрузка в настройках проектора. |
| Приложение вылетает | `adb logcat -s AndroidRuntime:E` и приложите вывод к задаче. |
