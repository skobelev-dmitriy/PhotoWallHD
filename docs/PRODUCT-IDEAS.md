# Продукт, монетизация и идеи (заметки из обсуждений)

Это рабочие заметки, а не решения. Всё помеченное «гипотеза» не проверялось.

## Позиционирование

«Ваш чёрный прямоугольник больше не чёрный»: любой телевизор или проектор на Android становится большой цифровой рамкой / живой картиной:
свои фото, плейлисты, «живые» эффекты, параллакс, атмосфера (камин, аквариум, дождь, снег), дискотека, управление с телефона.
Идея «замедлиться и рассматривать картину», а не листать быстро. Ближайший аналог по смыслу — Samsung Art Store для The Frame
(по сообщениям, около $4.99 в месяц или $49.99 в год в США, £39.99 в год в Великобритании; см. [Samsung UK](https://www.samsung.com/uk/lifestyle-tvs/the-frame/art-store-offer/)).
Наше отличие: любое дешёвое Android-устройство и свои фото.

## Бесплатно и платно (гипотеза)

- Бесплатно: слайд-шоу своих фото, часы, расписание, загрузка с телефона.
- Premium: дискотека, «живые» фото и параллакс, атмосферные сцены, каталог картин, плейлисты по расписанию, удаление рекламы, если она будет.
- Реклама на картине-обоях противоречит смыслу продукта; по стороннему источнику, баннеры AdMob на Android TV не поддерживаются (не официально, проверить).
- Серверная часть («живые» фото считает контейнер `vision/`) — естественное основание для подписки.
- Бизнес-вариант (кафе, салоны, отели, офисы): подписка за экран, удалённое управление. Пересекается с проектом ADS Network (его код я не видел).

## Контент

- Картины музеев: многие коллекции в общественном достоянии, но лицензию и условия API каждой коллекции проверять отдельно.
- Камин, аквариум, природа: нужны видео в приложении (сейчас нет) и права на ролики; ролики с YouTube брать нельзя. Альтернатива — процедурные сцены кодом.
- Диафильмы (идея с Stripa, см. ниже).

## Google Play: что нужно

- Личные аккаунты, созданные после 13.11.2023: закрытое тестирование ≥12 тестировщиков 14 дней до продакшена
  ([справка](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en-GB)). Организации освобождены.
- Платные функции из Вьетнама: в 2014 Вьетнам добавили в список стран продавцов; актуальность проверить в Play Console.
- ТВ-приложение: `LEANBACK_LAUNCHER`, `android.software.leanback`, «сенсорный экран не обязателен», баннер 320×180 **с текстом** ([документация](https://developer.android.com/training/tv/get-started/create)).
- Сделать до публикации: AAB и собственный ключ подписи (ключ `debug.keystore` публичный), политика конфиденциальности, анкета безопасности данных,
  обоснование разрешений («поверх окон», микрофон, сервис в фоне), код сопряжения для веб-управления (сейчас PIN по умолчанию не задан), QR-код с адресом,
  мастер первого запуска, **проверка на реальном проекторе**.

## Порядок работ (предложение)

1. Довести до выпуска (пункты выше).
2. Редактор слоёв для каждого фото («как в Photoshop»): слои эффектов, параллакс, атмосфера, включение/выключение каждого слоя, переключатель «оригинал / с эффектами».
3. Параллакс: карта глубины в контейнере (Depth Anything V2 Small — по вторичным источникам Apache-2.0; Base/Large некоммерческие; проверить по репозиторию) и эффект `parallax` в сетке.
4. Атмосферные сцены (процедурные, потом видео).
5. Каталог картин из открытых коллекций.
6. Облачный сервис и подписка; бизнес-режим.

## Stripa × диафильмы

Stripa (`skobelev-dmitriy/stripa-landing`, файл `stripa-decisions.md`) — платформа вебтунов и комиксов: Next.js + FastAPI + PostgreSQL + Celery, S3/CDN,
CBZ-импорт с `info.json`, Media Worker (нарезка, WebP/AVIF), ручная модерация, комиссия 30 %, ЮKassa, Android-обёртка Reader, отдельный TV-режим
с горизонтальными панелями.

Идея: диафильмы (кадры в отдельных файлах) читать на проекторе как «диафильм на стене»: кадр за кадром, листание пультом, подписи, возможно озвучка;
плейлист = серия. Горизонтальный кадр подходит проектору лучше вертикального вебтуна. Общие части: Media Worker и наш контейнер улучшения/анимации.

**Права — главный риск.** Диафильмы советской эпохи не становятся свободными автоматически: у текста и рисунков есть авторы; по общему правилу в РФ
авторские права действуют 70 лет после смерти автора, поэтому многие работы ещё защищены (проверять по каждому произведению; это не юридическая консультация).
Парсинг чужого сайта, публикация собранного и «улучшение» нейросетью (это производное произведение) создают риск жалоб и блокировки в магазинах приложений.
Безопаснее: внутренние тесты без публикации; произведения с истёкшими правами; договор с правообладателями; новые диафильмы по текстам в общественном
достоянии с новыми иллюстрациями (в том числе нейросетевыми).
