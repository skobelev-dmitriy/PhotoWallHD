# Спецификация «живых» эффектов (v1)

Единый контракт между сервисом распознавания (`vision/`, Python), страницей предпросмотра и приложением на проекторе (Kotlin,
`LiveMath.kt`). **Формулы ниже реализованы дважды** (`vision/app/effects.py` и `app/.../LiveMath.kt`), и тест сверяет их числа.
Это наши собственные эффекты в духе Wallpaper Engine (маска + эффект + параметры), а не копия его шейдеров.

## Идея

Фото остаётся фото. В нескольких областях (маски) пиксели чуть смещаются по времени: вода покачивается, листва на ветру,
облака медленно дышат, человек едва заметно «дышит». Амплитуды очень малы: картина кажется статичной, но «живой».

## Рецепт (recipe.json)

```json
{
  "version": 1,
  "image": {"width": 4000, "height": 3000},
  "backend": "classical",
  "layers": [
    {
      "id": "water-1", "class": "water", "label": "sea", "effect": "ripple",
      "confidence": 0.6, "enabled": true, "strength": 1.0,
      "bbox": [0.0, 0.62, 1.0, 1.0],
      "area": 0.31,
      "params": {"amplitude": 0.0016, "wavelength": 0.12, "speed": 0.35, "perspective": 0.7},
      "mask": "water-1.png"
    }
  ]
}
```

- `bbox` — `[u0, v0, u1, v1]` в долях ширины/высоты изображения.
- `mask` — 8-битный PNG в градациях серого (0 — не двигать, 255 — полностью), с мягким краем.
  В ответе сервиса вместо имени файла поле `mask_png_b64`.
- `strength` — множитель амплитуды слоя (ручной регулятор); `enabled` — включён ли слой.

## Координаты

`u = x / W`, `v = y / H` ∈ [0, 1], `aspect = W / H`, `TAU = 2π`, `t` — время в секундах.
Смещение `(dx, dy)` измеряется в **долях ширины**. Пиксель назначения берёт цвет из источника

```
u_src = u − dx_total
v_src = v − dy_total · aspect
```

где `d_total = Σ слоёв ( enabled · strength · gain · m(u, v) · d_layer(u, v, t) )`, `m` — значение маски, `gain` — общий множитель
(1 — как есть; на предпросмотре можно ×3, чтобы лучше видеть).
`A` — `params.amplitude`, `f` — `params.speed` (циклов в секунду).

## Эффекты

Во всех формулах `t` входит только с **целыми** множителями при `f`: поэтому при `t → t + 1/f` картинка точно повторяется
(нужно для бесшовных петель в предпросмотре).

### `ripple` — вода (море, озеро, река, бассейн)
Параметры: `amplitude` (≈0,0016), `wavelength` (в долях высоты, ≈0,12; не меньше ≈0,08), `speed` (≈0,35), `perspective` (0…1, ≈0,7).
Волна намеренно плавная («зыбь»): приложение рисует её сеткой из ~128 узлов по ширине, более мелкая рябь на такой сетке дрожала бы.
Вдали рябь должна быть слабее (ту же проблему отмечает урок Wallpaper Engine): вес растёт сверху вниз по области.

```
g  = clamp((v − v0) / (v1 − v0), 0, 1)           # v0, v1 — верх и низ bbox
w  = (1 − P) + P·g                                # P = perspective
s  = v/λ + 0.37·u·aspect/λ                        # λ = wavelength
dx = A·w·( sin(TAU(s − f·t)) + 0.5·sin(TAU(1.6·s + 0.31·u·aspect/λ + 2·f·t)) ) / 1.5
dy = 0.35·A·w·cos(TAU(1.3·s − f·t + 0.25))
```

### `sway` — листва, пальмы, трава
Параметры: `amplitude` (≈0,004), `speed` (≈0,25), `spatial` (≈3: сколько фаз укладывается по ширине).
Основание неподвижно, верх качается сильнее.

```
h  = clamp((v1 − v) / (v1 − v0), 0, 1) ^ 1.5
ph = TAU·(f·t + K·u)                              # K = spatial
dx = A·h·( 0.7·sin(ph) + 0.3·sin(2·ph + 1.1) )
dy = 0.15·A·h·sin(ph + 1.7)
```

### `clouds` — небо с облаками
Параметры: `amplitude` (≈0,002), `speed` (≈0,05). Очень медленное низкочастотное «дыхание».

```
dx = A·( sin(TAU(0.7·u + 0.3·v − f·t)) + 0.5·sin(TAU(1.9·u − 1.1·v − 2·f·t) + 1.0) ) / 1.5
dy = 0.4·A·sin(TAU(0.5·u + 0.9·v − f·t) + 2.0)
```

### `breathe` — человек, животное
Параметры: `amplitude` (≈0,002 — доля масштаба), `speed` (≈0,2). Масштабирование вокруг низа области.

```
s  = A·sin(TAU·f·t);   k = s / (1 + s)
ax = (u0 + u1)/2;      ay = v1
dx = (u − ax)·k·0.5
dy = (v − ay)·k / aspect
```

### `flow` — флаг, штора, ткань
Параметры: `amplitude` (≈0,006), `wavelength` (в долях высоты, ≈0,15), `speed` (≈0,5).

```
dx = A·sin(TAU(v/λ − f·t) + TAU·0.3·u·aspect/λ)
dy = 0
```

## Что пока не умеем

Платье и волосы «по ветру» как у Wallpaper Engine мы не повторяем: для этого нужны отдельные маски деталей и физика/нейросеть.
Классы людей даём только с «дыханием» (`breathe`). См. [EFFECTS-IDEAS.md](EFFECTS-IDEAS.md).
