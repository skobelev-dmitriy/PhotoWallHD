# MCP-сервер: управление проектором голосом и текстом

`mcp/` — небольшой MCP-сервер (Node.js ≥ 18), который превращает HTTP API проектора ([API.md](API.md)) в инструменты для Claude.
Можно сказать: «включи дискотеку на проекторе», «добавь эту картину», «поставь смену фото раз в минуту», «выключи показ».

## Инструменты

| Инструмент | Что делает |
|---|---|
| `projector_status` | Что сейчас на экране (показ с именем фото / дискотека с эффектом / ничего), число фото, свободное место, настройки. |
| `see_screen` | Картинка того, что сейчас на проекторе: кадр текущего фото или снимок эффекта дискотеки. Удобно, чтобы проверить, что команда сработала. |
| `list_photos` | Список фото в порядке показа. |
| `add_photo` | Загрузить картинку (необязательно — в папку) по URL (или по пути к файлу, если сервер запущен на вашем компьютере). |
| `folders` | Создать, переименовать, удалить папку; переместить фото в папку. |
| `playlists` | `list` / `create` / `update` / `delete` / `play` / `set_schedule_mode`: плейлисты из папок и фото с окнами времени («утро», «вечер»). |
| `delete_photos` | Удалить фото по именам (помечен как разрушающий — Claude должен переспросить). |
| `slideshow` | `start` / `stop` / `next` / `prev` / `pause` / `resume`. |
| `disco` | `start` / `stop` / `next_effect` / `prev_effect`, плюс эффект, источник звука (`remote` — браузер), чувствительность, вспышки. |
| `update_settings` | Любые настройки: интервал, переход, масштаб, часы, затемнение, расписание, параметры дискотеки. |

## Установка (для Claude Code / Claude Desktop на вашем компьютере)

```
cd mcp
npm install
```

Claude Code:

```
claude mcp add photowall --env PHOTOWALL_URL=http://192.168.1.50:8080 -- node D:\!Projects\PhotoWallHD\mcp\server.js
```

Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "photowall": {
      "command": "node",
      "args": ["D:\\!Projects\\PhotoWallHD\\mcp\\server.js"],
      "env": { "PHOTOWALL_URL": "http://192.168.1.50:8080", "PHOTOWALL_PIN": "" }
    }
  }
}
```

`PHOTOWALL_URL` — адрес с главного экрана приложения. Если в настройках задан PIN, добавьте `PHOTOWALL_PIN`.
Чтобы адрес не менялся, закрепите за проектором постоянный IP в роутере (DHCP reservation).

Проверка без проектора: `npm test` (поднимает поддельный проектор и общается с сервером как настоящий MCP-клиент).

## Важно: откуда это работает

MCP-сервер должен «видеть» проектор, а проектор стоит в вашей домашней сети. Поэтому:

- **Работает:** Claude Code и Claude Desktop на компьютере в той же сети (режим stdio, как выше).
- **С телефона:** если на домашнем компьютере запущена сессия Claude Code с этим MCP-сервером, а приложение Claude на телефоне
  управляет этой сессией (Remote Control), команда голосом с телефона дойдёт до проектора. Условие — компьютер включён и дома.
  Эту связку я не проверял.
- **Не работает «из коробки»:** подключение как коннектор в claude.ai / приложении на телефоне напрямую. Такие коннекторы живут в
  облаке и до адреса вроде `192.168.x.x` достучаться не могут. Нужен публичный HTTPS-адрес и, для коннекторов claude.ai, обычно OAuth.
  Поэтому не открывайте порт проектора в интернет: PIN и открытый HTTP — не защита от интернета.

### Режим HTTP (для домашнего сервера, NAS, Raspberry Pi)

```
PHOTOWALL_URL=http://192.168.1.50:8080 MCP_TOKEN=<длинная случайная строка> node server.js --http 3333
```

Слушает `127.0.0.1:3333/mcp`, каждый запрос должен нести `Authorization: Bearer <MCP_TOKEN>`; адрес меняется переменной `MCP_HOST`.
Здесь отключено чтение локальных файлов (`add_photo` принимает только URL). Дальше его можно выставить наружу через защищённый
туннель, но тогда вы отвечаете за защиту: токена в заголовке мало для коннектора claude.ai (ему нужен OAuth), и каждый, кто достучится
до сервера, управляет вашим проектором. Готового решения для телефона-напрямую здесь нет, это отдельная работа.

## Что можно улучшить

- OAuth для подключения как удалённого коннектора claude.ai.
- Инструмент «показать именно это фото сейчас» (в приложении такого API пока нет).
- Автопоиск проектора в сети (mDNS), чтобы не указывать IP.
